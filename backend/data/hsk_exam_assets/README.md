# HSK listening exam assets

These files were copied from the local D: drive seed package. Each folder contains
an exam listening recording and, where provided, the answer PDF and test PDF.

The package IDs are preserved because they do not reliably encode the HSK level.
They must be mapped to a level in the backend before being shown in a mock test.
The files are kept as local development assets and should not be published unless
the project has distribution rights for them.
