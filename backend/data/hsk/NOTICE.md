# HSK vocabulary data — sources & licences

The official syllabus portion of `hsk30.json` is generated by `scripts/build_hsk30.py` for **levels 1–6** of the current official HSK syllabus
(*HSK 考试大纲*, published 2025-11, in force from 2026-07). A user supplied Pleco export adds flashcards for levels 1–9 below.

| Part | Source | Licence |
|---|---|---|
| **Words, levels, readings, parts of speech** | Official syllabus, 中外语言交流合作中心 (CTI) — rows extracted and validated by `scripts/extract_hsk_syllabus.py` into `syllabus_vocab_l1-6.json` (all 11,000 rows were numbered and checked against the syllabus totals) | Public standard document; factual word list, attribution given |
| English meanings, traditional forms, frequency rank | [drkameleon/complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary) | MIT |
| English meanings for words missing above (≈150, mostly new in 2025) | [CC-CEDICT](https://cc-cedict.org/) (MDBG) | **CC BY-SA 4.0** — attribution required; derived data must stay under the same licence |

Hand-written meanings are marked `"definition_quality": "manual"` in the JSON.
Earlier versions of this app used the 2021 draft of HSK 3.0, whose level boundaries differ; do not mix the two.

## User supplied Pleco deck

`hsk30.json` also includes the user's `HSK3.0 flashCARDS-2611220148.xml` Pleco export,
created by Pleco User -1 with Pleco 2.0 Flashcard Exporter. The import uses the deck's
HSK 3.0 level categories 1–9, retains its simplified/traditional forms, readings and
dictionary entries, and tags imported rows with source provenance. The deck groups
legacy categories 1–6 and the current advanced level 7–9 category. The import contains
12,248 cards; one export card has no HSK assignment and is omitted. Imported cards are
grouped into the app's `HSK7-9` band because the export does not separate advanced levels
7, 8 and 9 further. Original official syllabus levels remain in `syllabus_seq` and are
not replaced by Pleco categories.
Pleco's dictionary definitions include example sentences and Chinese text; attribution
and any applicable source licence terms remain attached to the imported material.
